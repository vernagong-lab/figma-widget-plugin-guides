首次設定

請在 Figma Development 區分別匯入 Checklist Widget 與 Whoscall x Lokalise Plugin；Whoscall x Lokalise Plugin 可從任一入口開啟。

01匯入 Checklist Widget選擇 manifest.json
02匯入 Plugin選擇 lokalise-plugin/manifest.json
03開啟 Settings在 Whoscall x Lokalise Plugin 輸入設定
04測試連線確認可讀取 key／翻譯

請完整填寫以下設定，才能使用 key、翻譯、截圖、comment 預填與 Branch 多語系流程。

欄位說明
Lokalise API Token在 Lokalise 建立的 API Token，供讀寫 key、翻譯與截圖。
Lokalise Project ID要操作的 Lokalise 後台專案 Project ID；請從該專案資訊複製。
Base language上傳原文所使用的 Lokalise 語言代碼，通常為 en。
Platform選擇 Android 或 iOS，決定 Branch 多語系輸出的語系數量。
CORS Proxy URLFigma Desktop 面板連線 Lokalise 必填。請直接填入 https://lokalise-plugin.verna-gong.workers.dev。
Figma Personal Access Token（PAT）供讀取 Figma comments 作為 key 建議。到 Figma 檔案瀏覽頁左上帳號選單 → Settings → Security → Personal access tokens 建立並立即複製；token 僅會顯示一次。查看 Figma 說明
Figma File Key開啟目前 Figma 檔案並複製檔案連結；網址中 /design/<File Key>/（或舊網址 /file/<File Key>/）之間的字串就是 File Key。也可直接貼完整 Figma 檔案網址。查看 Figma 說明
Branch 的設定空白？可到 Settings 使用「Import settings from main file」。Branch 本身仍要有可用 Figma PAT 才能讀取 main file 的設定。

同步到 All UI

01前往來源 Page確認要同步的 frame 位於目前 Page
02完成 checklist未完成項目會阻擋同步
03按 Sync to All UI同步目前 Page 的來源 frames
04檢查 All UI確認 Section、文案、文字變數與版面
  • 只同步目前 Page、名稱結尾為 _Main 的 frame。
  • 建議命名：{Project}_{Page}_{Status}_Main；不符合格式的項目會放到 Misc。
  • 重新同步會用來源內容更新對應 All UI frame，請不要把唯一版本的手動修改只留在 All UI。

指派 key、Export 與 Import

01選取文字選取一或多個 text layer
02Key Setup輸入、搜尋或採用 comment 建議
03Assign / Export存 key，或連同原文與截圖上傳
04Import選語言後 Preview／Pull 翻譯

Assign 與 Assign & Export

  • Assign：只儲存 key 到 Figma。
  • Assign & Export：以目前畫面中的 key 值直接上傳。
  • Char limit（String 字元限制）：在每個 key 的 Char limit 填入最大字數；Assign 會存到 Figma，Export 時會同步到 Lokalise。留白代表不設定限制。
  • 截圖：若要把標記截圖上傳到 Lokalise，務必開啟 Update screenshots。每個 key 會取得一張完整 UI 圖，且只以唯一藍框標出該 key 的文字位置。
  • Comment 顯示的是建議，不等於已儲存；仍須 Assign。

Import 翻譯

  • 建議先用 Preview 檢查大量改動。
  • 目前請以整個 Page 的 Pull 為準；選取範圍與還原選項的限制見下方「目前不要依賴的選項」。
同一次 Export 不可重複 key若兩個選取文字圖層使用同一 key，工具會停止上傳。請先回到 Key Setup，讓每個需要截圖的文字使用不同 key。

Branch mode 只能在 Figma branch file 使用。在 branch 的來源 Page，直接把 Checklist Widget 右上切到 Branch。舊版 Settings 勾選流程已不再使用。

注意事項與排查

情況先檢查什麼？
Plugin 無法連線／Failed to fetch確認 Lokalise Token、Project ID、CORS Proxy URL；Figma Desktop 的面板需要 proxy。
Comment pre-fill 顯示 Token expired在 Settings 建立並填入新的 Figma PAT。
Export 被重複 key 保護擋下Key Setup 中有兩個選取文字使用相同 key；請修改其中一個。
Branch 沒有 JP／PH確認 Platform 是 Android；iOS 設計上只有四語系。
翻譯套了但顯示異常檢查 TH／TW／JP 的字型與字重；必要時人工調整。

目前不要依賴的選項

Key pattern / Key case 的自動產生 key
Include hidden layers
Auto-link existing translations
Import selected keys only：只限制抓取哪些 key；同 key 的其他文字仍可能一起更新，不是嚴格的「只更新所選文字」。
Import selected frames only：直接套用雖會限在所選 frame，但自動連結可能影響同頁其他未指派文字。
Restore original text：只在同次開啟面板期間保存，且以 key 而非文字節點記錄；重複使用 key 時不保證能還原正確原文。
